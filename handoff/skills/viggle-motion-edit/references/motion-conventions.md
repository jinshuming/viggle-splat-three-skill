# 动作格式约定

依据 npm `@viggle/splat-engine-three@0.1.1`。完整骨骼名及静止变换见 `rig-441.json`。白色小丑和两段舞蹈均为 441 骨骼；舞蹈为 451 帧、25 fps。其他素材按文件实测。

- **朝向：**右手系、米、`+Y` 向上；静止人物局部 `+X` 朝前、左侧 `−Z`。白色小丑头→鼻尖约为 `(+0.124,+0.026,0)` 米。世界方向还受对象及父对象旋转影响。导入外部动作时测量源朝向，再统一转换姿态和骨盆轨迹。
- **骨架：**GLB 使用 `skins[0].joints`；插件按名称匹配 canonical 骨架，节点顺序可变。只要求动作骨骼名称与 canonical 骨架匹配：身体 86 骨（索引 0–85）必须齐全且唯一，面部骨骼可有可无（仅身体的 86 骨动作合法，不驱动面部）；不在 canonical 骨架内的关节被忽略。每个匹配到的骨骼恰有一个旋转轨道。支持 `LINEAR`、`STEP`、`CUBICSPLINE`；时间轴需均匀，每轨道使用主时间线或单个常量键。`weights` morph 轨道不驱动骨骼。
- **位移：**恒定局部 translation 是骨长声明，变化值才是动作。身体骨长应保持恒定；面部表情主要依赖变化的局部 translation。旋转四元数应归一化，scale 不要代替皮肤权重或关节修正。
- **Root motion：**运行时 `root` 姿态被钳到 bind；骨盆骨内 `X/Z` 始终被钳制。`off` 原地播放，`apply` 将骨盆水平位移写到角色 pivot，`extract` 输出逐帧增量。不要只改 root 轨道来转身。
- **落脚：**先关闭 `groundLockY` 和 `lockPelvisY` 检查原始轨道，再按动作需要启用。锁地会掩盖脚步或骨盆偏移，不修复权重拉丝。

`inspect_motion.py` 只检查文件结构；画面须用目标插件播放，检查面部骨骼是否有 `.vsplat` 权重，以及脚底、肘腕、循环边界的实际效果。
